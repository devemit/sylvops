SYLVOPS 0.1.0 TEST BUILD
================================

Requirements:
- 64-bit Windows 10 or Windows 11
- Git available on PATH
- A local Git repository to open

No Rust installation or Visual Studio Build Tools are required.

Double-click "Start SylvOps.cmd". Enter a Git repository path when
prompted. The launcher starts the daemon, registers the repository, creates a
plain-shell session on first use, and opens the terminal UI.

Useful keys:
- Tab or h/l: move between panels
- j/k: move selection
- Enter: attach to the selected session
- Ctrl+]: detach without stopping the session
- g: show the bounded Git diff
- Shift+A: select the highest-priority attention item
- ?: show help
- q: close the UI while sessions continue

To stop the daemon, open PowerShell in this directory and run:

  .\sylvops.exe daemon stop

This is an unsigned development build, not a production release.
