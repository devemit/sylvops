SYLVOPS 0.1.0
================================

Requirements:
- 64-bit Windows 10 version 1809 or newer, or Windows 11
- Git available on PATH
- A local Git repository to open

No Rust installation or Visual Studio Build Tools are required.

Open PowerShell in this directory and run the launcher with a Git repository:

  .\Start-SylvOps.ps1 -Repository C:\path\to\repository

From Command Prompt, the equivalent is:

  "Start SylvOps.cmd" "C:\path\to\repository"

If no repository argument is supplied, the launcher uses the current
directory. It starts the daemon, registers the repository idempotently, and
opens the native desktop. It does not start a shell or agent until you
explicitly create a session. In the desktop, use the guided Workspace ->
Project/root Worktree -> Session flow. Shell is selected by default;
attaching to a session is always explicit.

For the keyboard-first terminal UI, open PowerShell in this directory and
run:

  .\sylvops.exe tui

In the TUI, Tab switches between Explorer and Main; arrow keys or j/k move
through the hierarchy; Left/Right or h/l collapse and expand; 1/2/3 select
Terminal/Changes/Details; Enter performs the explicit primary action; and
Ctrl+] detaches without stopping a session. Press ? for the complete current
shortcut list. Press q to close the TUI while sessions continue.

Closing either client leaves daemon-owned sessions running. Reopen the
desktop with the launcher command or reopen the TUI with the command above.

To stop the daemon, open PowerShell in this directory and run:

  .\sylvops.exe daemon stop

This is an unsigned portable build. Windows may show an unrecognized-app warning;
verify the archive checksum before choosing More info -> Run anyway.
